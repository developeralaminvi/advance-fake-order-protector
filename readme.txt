Advanced fake order protector for Bangladeshi WooCommerce stores with phone number validation, 1-click IP/phone blocklist, repeat order protection, real-time incomplete orders tracker, and Steadfast & BDCourier delivery ratio analytics.

== Description ==

**Advance Fake Order Protector & Courier Checker** is an all-in-one fraud prevention, security, and abandoned order recovery plugin specifically crafted for WooCommerce e-commerce businesses in Bangladesh.

### Key Features:
* **Bangladeshi Phone Number Validation**: Validates 11-digit Bangladeshi mobile numbers (013-019 prefixes) and catches fake/dummy numbers (e.g., 01700000000, 01234567890) with stylish popup alerts.
* **1-Click IP & Phone Blocklist in Orders Table**: Block or unblock any customer phone number or IP directly from the WooCommerce Orders table without page reload, accompanied by instant toast notifications.
* **Blocked User Support Redirection**: Blocked visitors receive a custom warning modal with a direct 1-click WhatsApp support button.
* **Duplicate / Repeat Order Detector**: Protects against accidental or fraudulent repeat orders of the same product within a configurable time limit (e.g., 60 mins), prompting the customer with an interactive Confirm / Cancel popup modal.
* **Real-time Incomplete Order Capture**: Automatically saves checkout leads the moment a valid 11-digit phone number is entered. Automatically clears or converts them when an order is placed.
* **Courier Delivery Ratio & Fraud Checker**: Live courier delivery success rate, return rate, total parcel history, and risk assessment powered by BDCourier and Steadfast APIs, visualized with gauges and breakdown tables.
* **Admin Settings Panel**: Comprehensive settings for WhatsApp integration, repeat order intervals, blocklist management, and courier API keys.

== Installation ==

1. Upload the `advance-fake-order-protector` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to `Fake Order Protector` -> `Settings` to configure your WhatsApp support number and courier API credentials.
